Display

Standard base game — all 7 roles and 15 Events, 2–5 seats. Play from one browser, or use the Online button to play with others over the internet. Not yet included: the five custom roles, optional challenges and founding-date automation.

Play online

One player hosts and shares a room code or link. Everyone else joins from their own browser. No account is needed. Moves are passed along by a small relay server, so it works on any network.

How to host, join and resume

Start a new game (host)

  1. Type your name and click Host a new game. You get a room code and an invite link.
  2. Send the link or code to the others. They open this page, click Online, type their name and the code, and click Join.
  3. In the lobby, choose the number of players and Epidemics. Give each seat a role (the role menu) and a person (the person menu). Players can also click Take this seat.
  4. When every seat has a person, click Start game. Roles can only be set here, before the game starts.

Join a game

Type your name and the room code (or just open the invite link), then click Join. Pick a seat if you have not been given one. If your connection drops, the page reconnects by itself and you keep your seat.

Resume a game that was interrupted

  1. The host opens this page in the same browser on the same device that was hosting, then clicks Online.
  2. Click Resume hosting (not Host a new game). The same room code comes back and the game continues where it stopped.
  3. Everyone else clicks Join with the same code or link. They get their seats back by name.

Good to know

  • Host a new game always starts a fresh room and a fresh game. Use it only for a new game.
  • Only the host's browser can resume, and it remembers one room at a time. Hosting a new room replaces the remembered one.
  • Never open the same room as host in two windows or devices at once. They push each other out and the game keeps dropping.
  • The host's page runs the game, so the host should keep it open and awake (no sleeping laptop or locked iPad).

Relay server (advanced)

Online play goes through a small relay server so it works on any network. The address is built into this page. Only change it if you set up your own relay, and everyone in the game must use the same one. Leave it empty to use the built-in setting.

Leaving versus closing the window
  • Closing the window, refreshing, or losing your connection only pauses you. Guests can reconnect to their seat. The host can reopen this page and click Online then Resume hosting to bring the same room and game back.
  • Leave room as the host closes the room for good. Everyone is disconnected and it cannot be resumed. The board stays on your page as a one-screen game.
  • Leave room as a guest gives up your connection. Join again with the code to come back, and click your seat or ask the host to give it back.
  • Back to lobby (host) ends the current game for everyone so you can start a new one.
